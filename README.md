# نظام إدارة فريق التسويق والمساعد الذكي (AI Marketing Team Copilot & Client Hub)

منصة متكاملة لإدارة عمليات وكالات وفرق التسويق باللغة العربية (**RTL**) مدعومة بوكلاء ذكاء اصطناعي (**Google Gemini API**) لتوزيع المهام، دعم التنفيذ، تقييم أداء الفريق موضوعياً، ومتابعة العملاء.

## الميزات الأساسية
1. **نظام الصلاحيات والأدوار الحي (RBAC Live Switcher):** التبديل الفوري بين المدير العام (`CEO`)، مدير الحسابات (`Account Manager`)، والأدوار التنفيذية الـ 6 (`Content Creator`, `Graphic Designer`, `Video Editor`, `Media Buyer`, `Moderation`).
2. **مركز القيادة وتقييم الفريق (`/`):** مؤشرات الأداء الموضوعية (من 100) بناءً على الالتزام بالمواعيد، معدل القبول من أول مرة (`First-Time Approval Rate`)، جودة المخرجات، وسرعة الإنجاز، مع تحليلات الـ AI الأسبوعية.
3. **لوحة المهام الذكية ومقسم الحملات (`/workspace`):**
   - تحويل فكرة الحملة أو البريف إلى سلسلة مهام مترابطة موزعة على الأدوار تلقائياً (`AI Campaign Breakdown`).
   - درج المهمة التفاعلي (`Smart Task Drawer`) المزود بزر **"اسأل المساعد الذكي (Ask Role Copilot)"** المربوط تلقائياً بخزنة هوية العميل.
4. **بوابة العملاء وخزنة الهوية (`/clients` و `/clients/[id]`):**
   - 4 عملاء تجريبيين (قطاع الأغذية والحلويات، قطاع الكافيهات، قطاع الصيدليات، وقطاع الصناعة والتصدير B2B).
   - خزنة الهوية (`Brand Kit & Memory`: أكواد الألوان Hex، الخطوط، نبرة الصوت، الجمهور المستهدف، والمحظورات) + جدول المحتوى التفاعلي (`Content Calendar`).
5. **بوابة التقارير الذكية (`/reports`):** توليد ملخص أسبوعي/شهري تلقائي بالذكاء الاصطناعي يوضح إنجاز الباقة الشهرية وأداء الحملات الإعلانية (`ROAS`, `CTR`, `CPL`).

## طريقة التشغيل
1. تثبيت الحزم:
   ```bash
   npm install
   ```
2. إعداد متغيرات البيئة (اختياري — النظام يعمل فوراً بالبيانات التجريبية ويمكن إدخال مفتاح Gemini من داخل الواجهة مباشرة):
   انسخ ملف `.env.example` إلى `.env.local` وأضف `GEMINI_API_KEY`.
3. تشغيل خادم التطوير:
   ```bash
   npm run dev
   ```
